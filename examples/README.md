# Examples

- `shipwatch.yaml` — default config (`shipwatch init` writes the same file)
- `sources.yaml` — copy of the bundled source pack (real changelog URLs)
- `freewhirr.yaml` / `openrouter.yaml` / `openai.yaml` — LLM endpoint snippets
- `cron.sh` — weekly cron
- `weekly-briefing.yml` — GitHub Actions job (also lives in `.github/workflows/`)
- `briefing.md` / `briefing.json` / `briefings.xml` / `index.html` — sample
  extractive briefing from fictional fixtures (Acme AI, Contoso Models,
  Northwind Agents, Fabrikam Docs). Generated by
  `python examples/generate_sample_briefing.py`. Companies and products
  are invented.

CI fixtures live under `tests/fixtures/`. Do not attribute invented
shipping news to real companies.
